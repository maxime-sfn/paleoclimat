# Paléoclimatologie: analyse statistique des dates de floraison des cerisiers à Kyoto et de gel du lac Suwa

## Organization du git

Répertoire **"base_de_donnee"** : contient toutes les données de nos ressources en format csv.

Répertoire **"ressources"** : contient toutes les ressources (livres, données manuscrites du projet) et un bilbiographie.
